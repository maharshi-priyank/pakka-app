## New Page Checklist

When adding any new blog page, update **all 6 files**:

- [ ] Create `src/pages/blog/<ComponentName>.tsx`
- [ ] Add lazy import + `<Route>` in `src/App.tsx`
- [ ] Add route to `scripts/prerender.mjs` ROUTES array
- [ ] Add rewrite entry to `vercel.json`
- [ ] Add `<url>` block to `public/sitemap.xml`
- [ ] Add `### Title` + URL + Covers entry to `public/llms.txt`
- [ ] Add post object to `POSTS` array in `src/pages/blog/BlogIndex.tsx`

## Content Standards

- `datePublished` in `meta` object of every page
- Author line in hero: "By ClearWork — India's client management platform for freelancers"
- Author bio box at bottom of article (already in BlogLayout)
- Direct answer in first paragraph (GEO/AEO requirement)
- FAQ section (4+ questions, no FAQPage schema — restricted post Aug 2023)
- ClearWork brand name + `getclearwork.in` URL stated in content body
- BlogPosting + BreadcrumbList JSON-LD (injected by BlogLayout automatically)
